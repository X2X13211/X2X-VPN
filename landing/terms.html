1.1. Исполнитель предлагает Пользователю услуги доступа к виртуальной частной сети (X2X-VPN) на условиях, являющихся предметом настоящего Пользовательского Соглашения.

2. Описание услуги

2.1. X2X-VPN предоставляет автоматизированный интерфейс для приобретения и управления доступом к виртуальной частной сети (VPN), предназначенной для обеспечения безопасности, шифрования трафика и анонимности Пользователя в сети Интернет. Управление услугой осуществляется через телеграм-бота, расположенного по адресу @VPNcv2_bot.

2.2. Услуга X2X-VPN предоставляется Пользователям, имеющим устройство с доступом к сети Интернет и установленным приложением (клиентом) для подключения к VPN.
